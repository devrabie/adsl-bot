# 📱 دليل تشغيل بوت مراقبة خطوط يمن نت على تطبيق Termux (أندرويد)

هذا الدليل يوضح خطوات تثبيت وتشغيل البوت على هاتف أندرويد عبر تطبيق **Termux** مع دعم التثبيت التلقائي بالكامل لجميع المتطلبات.

> 💡 **ملاحظة هامة:** تشغيل البوت من داخل اليمن (عبر شبكة يمن نت أو إنترنت الهاتف يمن موبايل / يو / سبأفون) يضمن الاتصال المباشر ببوابة المشتركين (`adsl.yemen.net.ye`) دون مشاكل الحظر الجغرافي الخارجي.

---

## ⚡ التثبيت السريع بأمر واحد (One-Liner)

بعد تثبيت تطبيق Termux، افتح التطبيق والصق الأمر التالي واضغط Enter:

```bash
pkg update -y && pkg install -y git && git clone https://github.com/devrabie/adsl-bot.git && cd adsl-bot && bash setup_termux.sh
```

سيقوم السكربت تلقائياً بالتالي:
1. تحديث حزم Termux وتثبيت بيئة Python وأدوات الترجمة الأساسية (`clang`, `libffi`, `openssl` وغيرها).
2. إنشاء بيئة عمل افتراضية `venv`.
3. تثبيت كافة متطلبات ومكتبات المشروع (`aiogram`, `cryptography`, `httpx`, `openpyxl`, `apscheduler`...).
4. إنشاء ملف الإعدادات `.env` وتوليد مفتاح تشفير البيانات وحفظ التوكن ومعرف الأدمن.
5. تهيئة قاعدة البيانات.

---

## 🚀 طريقة التشغيل اليومية

لتشغيل البوت في أي وقت:

```bash
cd adsl-bot
./start_termux.sh
```

يقوم سكربت `start_termux.sh` تلقائياً بتفعيل `termux-wake-lock` حتى يظل البوت يعمل بالخلفية بكفاءة دون أن يقوم نظام أندرويد بإيقافه لتوفير الطاقة.

## 🔐 كيفية إضافة خط وفحص الكباتشا من التيليجرام

1. افتح البوت في تيليجرام واضغط `/start`.
2. اضغط على **➕ إضافة خط جديد**.
3. أدخل **رقم الهاتف الثابت** للخط (مثال: `249590`).
4. أدخل **كلمة المرور** الخاصة بالبوابة (مثال: `123456`).
5. سيرسل لك البوت صورة **رمز التحقق (Captcha)** مباشرة داخل المحادثة.
6. اكتب الأرقام الـ 5 الظاهرة بالصورة وأرسلها.
7. سيقوم البوت بالدخول للبوابة وتفعيل ميزة **"تذكرني" (Remember Me)** وحفظ الجلسة في قاعدة البيانات.
8. من هذه اللحظة، سيقوم البوت بتحديث الرصيد دورياً وإرسال التنبيهات والتقارير اليومية وملفات Excel **تلقائياً دون طلب كباتشا مجدداً**.

## ⚙️ إيقاف وتشغيل البوت في الخلفية

- لإيقاف البوت مؤقتاً: اضغط `CTRL + C` في شاشة Termux.
- للتشغيل كخدمة خلفية مستمرة (Background) حتى بعد إغلاق شاشة الأوامر:
```bash
nohup ./start_termux.sh > bot.log 2>&1 &
```
- لمتابعة السجلات في الخلفية:
```bash
tail -f bot.log
```
- لإيقاف البوت الذي يعمل في الخلفية:
```bash
pkill -f "python main.py"
```
